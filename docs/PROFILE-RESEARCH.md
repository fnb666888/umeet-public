# 个人主页与账号管理调研：知乎 / X / Reddit / Discourse

> 2026-11-07 · 配合 demo 升级。三个问题：账号管理放什么、个人信息放什么、要不要展示我的帖子/收藏/赞过/回复。

## 1. 四家怎么做「个人」

### 共同架构：两层分离
| 层 | 谁能看 | 放什么 |
| --- | --- | --- |
| **个人主页（Profile）** | 他人可见 | 身份展示 + 内容足迹（帖子/回复/收藏…） |
| **账号与设置（Settings）** | 仅本人 | 凭证、安全、通知偏好、隐私、危险操作 |

### 知乎
- 主页：头像/昵称/一句话简介/认证徽章（盐值、创作者等级）；数据条：关注者·关注了·回答·文章·想法·收藏夹；内容页签：回答/文章/想法/视频/收藏/关注的问题
- 资料编辑（还可放）：居住地、所在行业、职业经历、教育经历、勋章
- 账号与安全：绑定手机/微信/微博、设置密码、实名认证、设备管理、注销账号
- 特色：创作中心（阅读/赞同/收藏数据、创作分等级）、盐值（社区信用分）

### X
- 主页：头像+横幅、昵称、@用户名、简介(160字)、**地点、网站链接、加入时间**、关注/粉丝数、获认证徽章；页签：**Posts / Replies / Media / Likes**（Likes 已设为仅自己可见）
- 设置分组：Your account（用户名/邮箱/手机/密码/停用）、Security（两步验证）、Privacy、Notifications、Display
- 特色：Bookmarks 独立页；把"赞"默认隐私——**赞过是敏感足迹**

### Reddit
- 主页：头像、u/用户名、**Cake Day（加入纪念日）**、**Karma（发帖/评论分**开显示）、奖杯陈列；页签：**Overview / Posts / Comments / Saved / Hidden / Upvoted / Downvoted**（Saved/Hidden 仅自己可见）
- 设置：Account（邮箱/密码/三方连接）、Profile（展示名/关于/横幅）、Safety & privacy、Notifications、Feed、Deactivate
- 特色：Karma 把"社区贡献"量化出来；动态 Overview 混合时间线

### Discourse
- 主页：用户名/昵称/头像/简介/地点/网站、加入时间、**最近活跃**；统计卡：**浏览话题数、阅读帖子数、阅读时长、访问天数、送出/收到赞**——把"阅读"也算贡献
- 页签：Activity（Summary/帖子/回复/点赞）、**Badges 徽章**
- 偏好：Account（邮箱/密码/2FA）、Profile、Emails、Notifications、Categories&Tags、Interface
- 特色：信任等级 Lv0–4 由行为积累决定权限

## 2. 结论

### 个人信息（头像/昵称/简介之外值得放的）
1. **身份背书**：学校认证徽章、校区、院系/年级（校园社区核心信任来源，可选公开展示）
2. **量化贡献**：发帖数、回复数、获赞数、收藏数、加入时间（Reddit Karma / Discourse 统计卡模式）
3. **足迹页签**：帖子 / 回复 / 收藏 / 赞过——**要做，但"赞过"默认仅自己可见**（X 的隐私教训），收藏可让用户选择公不公开
4. 可选：兴趣标签、常用社区、链接（主页/联系方式）

### 账号管理（Settings）放什么
1. **个人资料**：头像、昵称、简介、校区/院系/年级、兴趣标签
2. **登录与安全**：手机号（改绑）、密码修改、微信绑定、**两步验证**、**登录设备管理**（踢下线）
3. **认证**：同校认证入口/状态（校园社区的身份核心）
4. **通知偏好**：回复、赞与收藏、关注更新、系统公告，逐项开关
5. **隐私**：资料可见范围、收藏是否公开、树洞匿名身份说明
6. **危险区**：导出数据、注销账号
