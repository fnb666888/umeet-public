# 设置页信息架构调研：知乎 / X / Reddit / Discourse

> 2026-11-07 · 问题：账号与安全一页塞太多东西。四家是怎么拆设置页的？

## 1. 四家的设置结构

### 知乎 —— 左侧竖导航，多分组
`/settings` 左侧固定子导航：
- **账号与密码**（手机/微信/微博绑定、密码）
- **个人资料**（头像、昵称、一句话介绍、居住地、行业、职业经历、教育经历）
- **消息与邮件**（关注我的、邀请我回答的、我关注的问题…逐项开关 + 邮件通知）
- **隐私**（屏蔽用户/问题、隐私保护、谁能看我的动态）
- 帮助中心、退出
特点：一屏一个主题，左侧导航常驻可切换，互相不打架。

### X —— 三大块 + 偏好细分
Settings 左侧导航：
- **Your account**（用户名/邮箱/手机/密码/停用）
- **Security and account access**（安全、应用与会话、已连接的应用）
- **Privacy and safety**
- **Notifications**
- **Preferences**（无障碍、显示、数据、语言）
特点：账号类和安全类**分开成两个一级项**；显示/语言/数据这类"通用偏好"独立成组。

### Reddit —— 分类横向页签
新版 Web 设置：**Account / Profile / Safety & privacy / Feed settings / Notifications** 顶部页签切换；Profile（展示名/关于/横幅）与 Account（邮箱/密码/三方连接）分家。
特点：危险操作（Deactivate）收在 Account 页尾部，不单列。

### Discourse —— preferences 多页签
`/u/用户名/preferences/`：**Account / Profile / Emails / Notifications / Categories & Tags / Interface / Apps** 左侧列表，右侧单表单。
特点：Interface（界面/语言）单列；每个页签就是一个主题，表单短。

## 2. 共同模式（结论）

1. **设置中心 = 左侧固定子导航 + 右侧单主题面板**（知乎/Discourse/X 全是这个骨架）；Reddit 用横向页签，本质相同。**绝不把所有设置堆在一页**。
2. 分组惯例高度一致，可归纳为五组：

| 分组 | 放什么 | 参照 |
| --- | --- | --- |
| **个人资料 Profile** | 头像、昵称、简介、身份字段、标签 | Reddit Profile / 知乎个人资料 |
| **账号与安全 Account & Security** | 手机/邮箱/密码、三方绑定、两步验证、**登录设备**、**认证**、危险区（导出/注销） | X 的 Your account + Security 两项 |
| **通知 Notifications** | 逐类通知开关 | 四家皆有 |
| **隐私 Privacy** | 可见范围、屏蔽 | X/知乎 |
| **通用 General / Interface** | 显示、语言、主题、数据与缓存 | X Preferences / Discourse Interface |

3. **危险区跟着"账号"走**（Reddit 收在 Account 尾部；X 收在 Your account），不单独成页，但要视觉降权 + 确认弹窗。
4. **认证/实名**属于账号身份 → 放"账号与安全"；**外观/语言/缓存**属于通用 → 放"通用设置"。

## 3. Demo 改造（本轮实现）
`#/settings` 重构为设置中心：
- 左侧子导航（桌面竖排 / 移动端横排）：**个人资料 · 账号与安全 · 通知偏好 · 隐私 · 通用**
- 个人资料：头像/昵称/简介/校区院系年级/标签 + 保存
- 账号与安全：手机/微信/密码/两步验证、同校认证、登录设备、危险区（导出/注销）
- 通知偏好：四类开关
- 隐私：主页公开/收藏公开 + 树洞匿名说明
- 通用：主题（浅色/跟随系统）、语言、字号、清除缓存
