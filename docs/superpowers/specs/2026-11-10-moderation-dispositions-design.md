# 内容与用户处置需求稿

2026-11-10，经本会话第 18 题确认。本文将已选规则落为实施依据，技术取舍列在最后一节。

## 内容处置

- 帖子和回复只提供「保留内容」「删除内容」两个处理结果。保留内容将举报记为已驳回并结案，删除内容进入可恢复的回收站。
- 删除内容默认只处理内容，可勾选「同时限制作者参与」，选择期限后一次提交。
- 社区管理人员只能在获授权的社区处置作者。全站管理员默认施加全站限制，可切换为内容所在社区。
- 恢复内容与解除用户限制分别决定。恢复内容后原举报保持已结案，追加恢复记录。
- 删除、警告、设置与调整限制必须填写原因。驳回与转交继续允许原因选填。

## 用户处置

| 处置 | 效果 |
| --- | --- |
| 警告 | 通知用户并记录，用户仍可正常参与 |
| 社区限制参与 | 限制指定社区的发帖、回复、投票和 Wiki 编辑，保留浏览和申诉 |
| 全站限制参与 | 限制全站发帖、回复、投票、Wiki 编辑及发送私信，保留登录、浏览和申诉 |
| 停用账号 | 暂停日常使用，保留查看处置、申诉及必要的账号安全操作 |

三种限制类处置均提供 1 天、7 天、30 天、自定义、永久。版主和拥有处置用户权限的群组成员可在负责社区执行永久限制。

同一用户、同一社区只存在一项有效的参与限制。再次处置更新原因和期限，新期限从本次提交起计算，保留每次变更记录。全站同类处置按相同方式更新。

各社区限制、全站限制参与、停用账号独立计时。停用结束后尚未到期的全站参与限制继续生效，全站处置结束后尚未到期的社区限制继续生效。

## 群组权限及账号保护

- 群组统一使用「处置用户」，包含警告、限制、调整和解除，授予时联动必要的用户查看权限。
- 版主和自定义管理群组成员仅可处置普通用户账号，范围限定到负责社区。
- 普通全站管理员可处置普通用户、版主和自定义管理群组成员。
- 全站管理员账号由超级管理员处置，超级管理员身份沿用已有站点转让及保护规则。
- 有权管理内容的人员仍可按内容规则处理管理人员发布的内容。
- 举报人身份继续仅向全站管理员显示。

## 申诉

- 同次删除内容并限制作者，可以通过一份申诉复核两项。
- 复核人分别决定是否恢复内容、是否撤销用户处置，统一提交。
- 整份申诉交给有权处理全部项目的人员。涉及全站处置由全站管理员复核，针对全站管理员账号的复核遵守超级管理员层级。
- 禁止复核自己作出的处置。
- 只复核被申诉的那次处置。后续又调整过限制时，原申诉通过应记录原处置撤销，当前限制由复核人另行决定是否解除。

## 迁移

| 现有处置 | 结果 |
| --- | --- |
| 社区禁言、社区封禁 | 社区限制参与 |
| 全站禁言 | 全站限制参与 |
| 全站封禁 | 停用账号 |

保留剩余期限、原因及历史。同一用户、同一范围的同类有效限制合并，取最晚到期时间，永久优先。迁移后的旧社区禁言也限制投票与 Wiki 编辑，全站禁言还限制发送私信。

## 页面交互

- 举报详情采用独立页面，搜索栏直接显示。选择删除后可展开同时处置作者，填写原因并统一提交。
- 用户详情展示当前状态和有效限制，通过「操作」菜单选择警告、限制、调整或解除，再显示对应表单。
- 社区「受限用户」默认涵盖全部社区受限用户，表格展示用户、原因和到期时间，点击进入详情。
- 管理记录按一次提交归为一条，概要写清全部结果，展开查看具体变更。
- 申诉详情按内容与用户处置分别选择维持或撤销，统一提交。

## 技术方案与实施取舍

采用复用现有 NestJS、Kysely、MySQL、Next.js、共享 Zod 合同的方案，保留现有举报、回收站、群组、管理记录和申诉入口。一次提交使用同一个操作标识，内部保存可独立复核的效果。

相比仅修改按钮与文案，此方案能落实组合处置、独立撤销和停用后的申诉。完整重建管理后台会扩大改动范围，本次沿用现有页面结构。用户已确认的交互及业务规则以本文前述各节为准。

以下为实施计划中的技术建议，实施时需接受验证。

- 同类限制采用追加版本和替代关系，在查询上只显示当前有效版本，以便旧申诉准确定位原处置。
- 旧权限中任一禁言或封禁授权转换为「处置用户」，现有成员、社区范围及其他权限保留。这会使原先仅有单项权限的群组获得统一处置权限。
- 停用账号通过受控登录进入专用处置页，允许查看自己的记录、提交申诉、退出登录和必要的凭证安全维护。普通身份认证入口默认继续校验停用状态。
- 页面继续使用紧凑表格、标题及分隔线。窄屏表格使用容器内横向滚动保留原因和期限。
- 自定义期限沿用现有小时单位及最多 8760 小时的校验，永久单独表示。统一按服务端时间计算和判断到期。
- 解除限制沿用原因必填。警告沿用现有可申诉路径。其他未纳入新操作菜单的历史细分限制保留原效果及可追溯记录。
