## 决策树

- 个人维护 + 预算 → 部署责任分配（自管主机 / 托管平台 / 托管数据库）→ 环境、发布、补丁与回退流程。
- 已选双地区 → 区分两地网站/API部署与数据库写入位置 → 海外目标区域、数据复制及故障接管要求 → 成本复核；未自动提升300元预算。
- 大陆海外同等重要 + 预算 → 首版主站位置与跨境实测 → 文件分发、缓存、域名及接入方案。
- 双端独立开发 + Wiki 双编辑模式 → 网站框架与编辑器组合 → 小程序编辑适配与原型验证。
- 统一后端 + 个人维护 → 主语言、后端框架、主数据库 → 任务、搜索、身份与外部服务。
- RPO 1h / RTO 4h → 数据库与文件的异机备份 → 保留期、加密、告警、恢复演练及核验。
- 自动检查与公开 UGC → 审核职责及自动检查供应商 → 失败重试、值守、紧急停止发布和权限审计。
- 公共资源下载 + 文件上传 + 预算 → 单文件与总量限制、出站流量预算、滥用限制、文件保留和清理。
- 四种登录 + 双端统一身份 → 主体和平台能力核验 → 登录绑定、供应商、发送额度、失败回退。
