# Umeet Makers Forecast Agent Implementation Plan

目标：将已确认的每日预测分析能力做成独立的 Makers Agent，供阿里云后端调用。

架构：LangGraph 固定单节点模型分析，输入题目、规则、截止时间和证据；输出使用 Umeet 现有 ForecastOutput 字段。相较开放研究 Agent，此方案限制工具权限和调用次数，便于控制免费额度。

- [x] 创建独立 makers-agent 项目、环境变量声明、鉴权及 SSE 响应。
- [x] 校验输入、概率范围、引用编号和截止时间。
- [ ] 类型检查、接口测试、完整 Makers 打包与本地预览。
- [ ] 用户登录，确认工作空间，选择实际可用模型并配置服务端密钥。
- [ ] 部署后验证远程接口及真实模型调用；主站 SSE provider 适配另行实施，不自动开启线上发布。

验证重点：无鉴权不得消耗模型；缺失配置失败关闭；未知引用不得发布；模型错误不泄漏凭据；中断和超时停止执行。
