# 社区管理工作台优化

延续已确认的社区管理方案，在当前 React、NestJS 和 MySQL 项目中完成以下工作。

- 全站后台使用 /admin，社区工作台使用 /moderation，共享登录账号。
- 复用 community_roles。daily、treehole、buddies 分别映射既有 campus、hollow、activities，其他社区保持原 slug。
- 全站管理员可授权社区主和版主，社区主可维护本社区版主。版主仅处理授权社区内容。
- 同一目标、相同处理状态的举报合并。结案提交包含实际举报编号，处置、结案、通知和管理记录在同一事务完成。
- 社区禁言只影响对应社区。私信举报和全站禁言仅全站后台可见和处理。
- 用户详情增加管理时间线和内部备注，内部资料仅管理接口返回。
- Wiki 显示最近修改与差异，支持保护。跨社区词条的管理修改要求拥有全部关联社区权限，恢复历史版本同样检查目标版本的社区范围。
- 帖子支持置顶、锁定和移动。移动需同时拥有来源和目标社区权限。

验证覆盖权限撤销、越权读取和写入、跨社区 Wiki、举报原子结案与重试、社区禁言、锁帖和普通用户操作。执行类型检查、集成测试、构建和本地浏览器检查。
