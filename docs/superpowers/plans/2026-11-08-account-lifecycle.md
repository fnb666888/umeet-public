# 网页账号生命周期实施计划

## 目标与设计

沿用 React、Next.js、NestJS、MySQL 8 和现有邮件验证码。补齐邮箱或用户名密码登录、账号内设置和修改密码、邮箱找回、安全记录与自主注销。用户已指定注销后保留公开贡献并显示已注销用户。

实现选择由本轮决定。找回使用独立 recovery 验证码用途，只允许已绑定邮箱恢复现有账号。请求响应统一，避免查询账号是否存在。设置密码后轮换当前会话并撤销其他设备。注销要求近期验证及手动输入确认短语，立即生效并撤销凭据和会话，用户名保留占位。

新 Wiki 贡献保存作者 ID。历史记录只有昵称时无法证明归属，避免根据昵称推断账号。已只读核对正式站，当前帖子和 Wiki 均为空，正式站新增贡献均可保存明确归属。

## 任务

- [x] 增量迁移 deleted_at，为新增 Wiki 贡献保存作者 ID。认证、会话签发与社区写入共同拒绝已注销账号。
- [x] 扩展现有密码服务支持已绑定邮箱登录与按账号资料设置密码，修复密码验证与并发变更之间的竞态。邮箱找回独立用途且不创建账号。
- [x] 账号概览显示密码登录标识与最近 20 条安全活动。注销事务清除登录凭据、个人资料、私人记录与本人发送的私信，保留公开贡献并匿名化。
- [x] 接通 React 登录、忘记密码、密码管理、安全记录和注销表单，复用邮箱重新验证。
- [x] 增加恢复用途隔离、验证码单次消费、过期与撤销、密码变更竞态、注销后重新登录与公开贡献保留测试，完成浏览器回归。
- [x] 构建并按后端、网页顺序发布，正式站执行无写入检查。

## 重点复核

注销与已验证密码登录、在途社区操作同时发生时不能恢复已注销账号或留下新个人状态。找回时邮箱已解绑不能新建账号。旧密码验证后密码已变化不能签发会话。邮箱本地部分保持现有大小写规则。失败表单保留输入，密码不写入日志与活动记录。



## 验证与发布结果

116 项自动化测试、类型检查、API 和 Web 生产构建通过。真实浏览器使用隔离数据库和注入邮件发送器，验证设置密码、确认不一致提示、邮箱找回、原账号恢复、重设密码、其他设备撤销、邮箱密码登录、安全记录、注销与公开贡献匿名保留，并检查 320、390、768、1440 四种宽度。补充社区发帖、回复、点赞、收藏、采纳和 Wiki 编辑修订记录回归通过。

2026-11-08 后端 example-api、网页 umeet-web-007 已接管全部流量。正式站浏览器检查通过登录与找回入口、首页、社区、Wiki、重定向、邮箱渠道和权限边界。本轮正式站验证未进行真实邮箱找回、密码变更或注销写入，完整写入流程由隔离测试环境验证。

本次产品决定采用立即注销、用户名保留占位、本人私信内容替换为注销提示。公开内容中的用户自行写入的正文保留，自动作者字段按用户 ID 匿名化。
