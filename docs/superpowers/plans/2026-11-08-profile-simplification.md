# 个人资料精简与用户名统一

## 目标与设计

按用户提供的知乎参考图制作横向封面、方形大头像、用户名编辑动作和分隔行简介。保留现有配色，白色内容、灰色分隔线与蓝色操作，左对齐，移动端纵向排列。资料只显示头像、用户名和简介。账号设置移除登录设备与安全活动区域。

新邮箱或微信账号自动生成唯一用户名。已有账号保留用户名并获得一次修改机会。沿用 3–32 位字母、数字、下划线或连字符的现有规则。内部 nickname 字段作为兼容字段同步用户名，页面统一称用户名。头像和简介独立保存，用户名单独确认修改并明确一次机会。

## 实施

- [x] 添加 017 数据迁移，记录 username_changes，补齐历史会员用户名，保持重复运行安全。
- [x] 新账号分配用户名，账号接口事务校验唯一性、一次修改配额，同步密码登录标识和资料名称，社区资料保存采用服务端名称。
- [x] 提取共享用户名编辑控件，重做资料页，移除昵称、学校资料、兴趣标签、注册后强制完善、设备与活动 UI。
- [x] 覆盖重名失败、并发改名、配额、旧账号迁移、资料保存绕过和密码登录回归。
- [x] 执行类型检查、测试、构建及本地浏览器桌面与移动端验证，提供本地预览。

## 验收重点

重名及无变化提交不扣次数，同时提交最多一次成功。密码和邮箱登录在改名后正常工作。旧资料中的名称不得覆盖账号用户名。头像和简介保存、刷新可恢复。所有工作在本地完成。
