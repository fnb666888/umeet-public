# Umeet 阿里云迁移计划

目标：将当前 Umeet Web/API 应用准备到用户现有 ECS，数据库由用户后续选择新的 MySQL 服务；不再依赖腾讯数据库，不删除原库或本地数据。

执行方式：本会话实现部署准备，完成后独立检查部署文件。

已知实例：杭州 `i-bp14bibhpmse8qali8c2`，Debian 13、2 CPU、约 1.7 GiB 可见内存、4 GiB swap、28 GiB 可用磁盘。原有 Node 为 20，不满足项目 Node 24 要求。当前无运行中的业务容器，未发现 HTTP 服务。

## 架构

- 隔离安装官方 Node 24，沿用项目 Next.js standalone 与 NestJS 编译产物。
- 新建版本目录，构建受内存约束，使用 systemd 以专用用户运行 Web/API。
- Web/API 仅绑定回环地址，正式 HTTPS 代理与域名切换等数据库就绪后再接入。
- 数据库通过服务器环境文件配置，不将密码写入源码、日志或命令行。
- 数据迁移通过单独受控命令运行；无数据库时不启动 API，不用样例数据冒充线上社区。
- 现有资讯、预测、Wiki 通知后台进程随 API 常驻运行；未来 Makers 是可选外部计算能力。
