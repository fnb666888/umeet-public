# 邮箱注册与密码验证流程

## 用户规则

注册输入唯一用户名、邮箱、密码并验证邮箱。注册后用户名允许修改一次，继续全站唯一。密码登录支持用户名或邮箱，邮箱验证码登录面向已有账号。修改密码要求原密码和已绑定邮箱验证码。忘记密码通过邮箱验证码直接重设密码。已有邮箱账号允许验证邮箱后补设首次密码。继续本地开发与预览。

## 实施设计

复用持久化验证码的限流、过期、尝试次数及事务消费逻辑，增加 register 和 password 用途。注册、密码修改、密码重置分别在一次数据库事务中完成验证和写入，失败时账号及凭据保持一致。找回密码表单直接提交验证码和新密码，验证码用途隔离。原认证绕过入口由 HTTP 层统一拒绝，内部凭据写入方法仅供已经完成验证的服务调用。
