# GitHub 私有仓库与微信云托管发布计划

## 目标和方案

使用一个 GitHub 私有仓库保存当前项目，通过 GitHub Actions 顺序发布现有微信云托管 API 和网站。用户已授权按此方案执行。正式发布分支采用 main，仓库名称采用 umeet。

## 执行步骤

- [ ] 将验证通过的 Dockerfile 和数据库启动程序保存到 rebuild。
- [ ] 添加源码白名单打包、官方 CLI 发布、任务等待和健康检查脚本。
- [ ] 使用 MySQL 8 执行测试，运行前后端类型检查和生产构建。
- [ ] 创建私有仓库并配置 GitHub Actions 的云托管凭据与服务参数。
- [ ] 检查待上传代码及 Git 历史中的已知密钥，提交当前网页项目和部署配置。
- [ ] 推送 main 并监控自动发布至完成，检查正式域名。

## 验证重点

- 共享 Markdown 和 contracts 源码全部包含在构建上下文。
- 排除本地环境文件、构建缓存、私钥和运行时数据。
- 单个生产发布串行执行，API 发布和健康检查失败时阻止网站发布。
- 云端任务完成且新版本承接全部流量后才报告成功。
- GitHub 仓库保持私有，CLI 私钥通过加密 Secrets 配置。
