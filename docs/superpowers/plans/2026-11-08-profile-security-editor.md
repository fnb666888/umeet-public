# 个人主页、账号设置与统一编辑器调整

## 已确认的交互

主页直接展示个性签名，点击签名原位编辑，点击头像直接上传并保存。账号设置采用白底、分隔行、灰色状态与右侧蓝色编辑入口，隐藏账号 ID。敏感操作从编辑入口进入邮箱身份验证弹窗，验证码按钮与输入框并排，验证后继续原操作。密码修改继续要求原密码和邮箱验证码。正文保留 Markdown 源码，提供内容与预览两个视图。工具栏插入格式标记，图片、表情和标签采用三个图标入口，沿用现有帖子存储格式并兼容旧草稿。

## 设计取值

沿用站点字体和蓝色 #3264d8。底色 #ffffff，正文 #20252b，辅助文字 #8793a5，分隔线 #e5e8ed。账号设置左对齐，认证弹窗标题和说明居中。编辑器工具栏紧凑，正文保留充足高度。

## 实施和验证

- 头像与签名在原位置编辑，用户名在账号设置中修改。
- 账号设置改为行布局，敏感操作接入自动续接的身份验证。
- 密码验证码先校验，再输入原密码与新密码，最终写入继续原子消费验证码。
- 发帖使用源码输入框与 Markdown 解析器，实现格式按钮、撤销重做与预览，兼容旧富文本草稿。
- 显示设置支持浅色、深色和跟随系统，选择保存在当前浏览器。
- 顶栏头像清除按钮内边距，在宽窄屏保持正方形裁切。
- 本地验证真实 API、数据库读写、验证码流程、富文本和 Markdown 发布回显，以及四种宽度。
- 本轮先在本地预览。
