# 群组管理实施计划

依据本会话已确认的群组管理需求稿，使用现有 Next.js、NestJS、Kysely 和 MySQL 实现。

## 约束

- 三个默认群组，版主通过群组统一授权，具体操作权限按社区合并。
- 超级管理员独享管理员任免与站点转让。
- 旧版主与自定义群组一次性重置，历史记录保留。
- 成员即时保存，权限与社区独立保存，独立详情和添加成员弹窗。

## 实施步骤

- [x] 合同与迁移。增加操作权限、默认版主记录、超级管理员信息及一次性重置迁移。
- [x] 后端。群组配置、批量成员变更、删除、站点转让均在事务中检查权限并记录审计。
- [x] 校验。所有管理入口按具体操作授权，社区申诉独立复核，账号保护按层级执行。
- [x] 前端。三列表格，成员与权限标签页，搜索多选弹窗，职责模板，路由返回和固定规则。
- [x] 验证。类型检查、权限及并发回归测试、浏览器流程与实际渲染检查，重启本地 API。

## 回归重点

- 多群组相同社区的权限合并及跨社区隔离。
- 只读权限无法调用写操作，取消查看时去掉依赖操作。
- 并发成员修改不覆盖其他变更，最后超级管理员保持有效。
- 申诉不可自审或跨社区操作，账号保护覆盖撤销与旧入口。
- 迁移仅运行一次，刷新或重启不会再次清空新配置。

## 验证结果

- 类型检查通过，前后端生产构建通过。
- 全量 39 个测试文件、141 项测试通过。
- 浏览器已验证多人添加、移除、刷新、浏览器返回、权限依赖、创建删除、超级管理员入口与 714 像素窄屏。
- 本地迁移已执行，旧版主及自定义群组已重置。首次超级管理员取现有有效管理员中注册最早的账号，本地为 admin_preview。
