# 私信改造实施计划

按已确认的调研方案，在当前会话中逐项实现。沿用 React、NestJS、MySQL。

## 数据与接口

- [x] 新增会话、成员设置、联系权限与举报表，旧消息建立已接受会话。
- [x] 独立接口提供会话列表、联系人搜索、消息分页、幂等发送、按消息位置已读。
- [x] 服务端执行消息请求、忽略、拉黑、限流与权限检查，旧发送入口复用规则。

## 页面

- [x] 独立私信组件，桌面双栏、手机列表与聊天切换。
- [x] 会话摘要、时间、未读数、搜索、新私信与请求页。
- [x] 每会话草稿、发送状态与失败重试、前台轮询和恢复补取。
- [x] 接受、忽略、拉黑、举报、免打扰、隐藏与联系权限。

## 验证

- [x] 集成测试覆盖隔离、并发请求、重试、旧记录、拉黑、已读边界。
- [x] 浏览器双账号验证收发、草稿切换、请求、菜单、窄屏与深色。
- [x] 类型检查、构建和完整测试。


## 验证结果

- 完整测试 32 个文件、129 项通过。
- 类型检查、API 构建、Web 生产构建通过。
- 本地浏览器三账号验证收发、请求、独立草稿、失败重试和刷新恢复。
- 验证 120 条新增消息补取、244 条历史分页、滚动提示、34 个会话分页与定时刷新。
- 320、390、714、1440 像素宽度及深色主题通过，无页面运行时异常。
- 默认首次联系一条请求，接受后继续。每人每分钟最多 20 条消息。聊天每 3 秒同步，站内其他页面每 12 秒刷新未读。
- 本阶段覆盖文本、表情和帖子卡片。图片、逐条引用回复和全文消息搜索留待后续。
