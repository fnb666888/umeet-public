# 整体排版与折叠策略调研：X / Reddit / Discourse（重点 Discourse）

> 2026-11-07 · 两个问题：什么信息横向排列、什么内容折叠起来。

## 1. 全局骨架对比

| 平台 | 骨架 | 列宽 |
| --- | --- | --- |
| X | 左图标导航 + **单列主栏** + 右栏（趋势/推荐） | 主栏固定 ~600px，右栏 ~350px；<1000px 右栏消失 |
| Reddit | 左社区导航（可折叠）+ 卡片流 + 右栏（社区信息/规则） | 主栏弹性；提供 卡片/紧凑 两种视图切换 |
| Discourse | 顶栏 + （可折叠）左侧分类/标签侧栏 + **单列内容** + 话题页右侧时间线 | 内容最大 ~1110px 居中 |

**共同点**：正文主列都有最大宽度（~600–1100px）；辅助信息全部横向挤出主列或折叠；窄屏只留单列。

## 2. Discourse 的排版细节（重点）

**横向排列的：**
1. **话题列表是"表格"**：`标题(弹性宽) | 参与者头像列 | 回复数 | 浏览数 | 活跃时间` 五列横向严格对齐——一屏能比较 20 个话题；分类徽章和标签内嵌在标题下一行。
2. **顶栏一排放下**：Logo、分类/最新/热门/未读页签、搜索（大而可展开）、🔔、头像、`+ 新话题`。
3. **话题页右侧"时间线"**：竖向进度条显示 当前楼层/总楼层，可拖动跳楼，底部悬浮"回复"。
4. 帖子底部的**参与者头像墙**横排（谁参与了这个话题）。

**折叠起来的：**
1. **长帖自动截断**："Show more" 展开全文。
2. **楼中楼折叠**：超过阈值的回复压成 `↩ 3 more replies` 一条横线；参与者头像条默认收起。
3. **引用块**：长引用默认折叠成一行摘要，点击展开。
4. **低质量帖被社区折叠**："post hidden by community flags"。
5. 左侧边栏可整体收起（hamburger）；通知横幅可关闭。
6. 话题读完自动接 **Suggested Topics**（相关推荐，一行横排卡片）。

## 3. Reddit / X 的对应做法
- **Reddit**：评论树每层有 `[–]` 一键折叠子线程（折叠后留"X points · hidden"一行）；列表提供 卡片/紧凑 视图；compact 视图就是 Discourse 式横排数字列。
- **X**：回复链用 "Show more replies" 分隔条折叠低质量回复；长文 "Show more"；右栏 <1000px 直接隐藏（不是折叠按钮）。

## 4. 结论 → demo 改造清单

**横向排列**：列表提供 **紧凑视图**（标题|作者|赞|回复|活跃 五列对齐，Discourse/Reddit compact 模式）；详情页互动条横排（已有）；帖子页右栏不再留空（放相关阅读）。

**折叠**：
1. 长帖 >320 字自动截断 + 渐隐遮罩 + 「展开全文」
2. 评论子树可 `[–]` 折叠（Reddit 式），已有"展开 N 条回复"保留
3. 话题结尾加 **相关讨论** 横排三卡（Discourse Suggested Topics）
4. 帖子页顶部加**阅读进度条**（Discourse 时间线的轻量替代）
5. 信息流加 卡片/紧凑 视图切换（记忆在会话内）
