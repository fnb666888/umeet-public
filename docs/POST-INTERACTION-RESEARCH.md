# 帖子编辑器与帖子交互调研：知乎 / X / Reddit / Discourse

> 2026-11-07 · 配合 demo 升级（`demo/web-ux/`）。聚焦两个问题：发帖编辑器怎么做、帖子除发帖/回复外还应有哪些交互。

## 1. 发帖编辑器对比

| 平台 | 编辑器形态 | 支持格式 | 内容上传 |
| --- | --- | --- | --- |
| X | 纯文本输入框 | 无（Premium 长文才有标题/粗斜体） | 图片×4 / GIF / 视频 / 投票 |
| 知乎 | 富文本工具栏（B/I/U/标题/引用/代码块/公式/链接） | 富文本；粘贴 Markdown 自动转换 | 图片 / 视频 / 公式 |
| Reddit | **双模式**：Fancy Pants 富文本 ↔ Markdown 源码，一键互切 | 富文本 + MD、表格、剧透标签 | 图片 / 视频 / 链接 / 投票 |
| Discourse | 纯 Markdown + 工具栏插入语法 + 分屏实时预览 | MD only（无富文本） | 拖拽/粘贴即上传图片 |

### 要点
1. **格式能力 = 社区气质**：X 用零格式换取速度；Discourse 用纯 MD 换取极客友好；Reddit/知乎用双轨兼顾小白与熟手。
2. **类型先行**（Reddit）：先选 帖子/链接/图片/投票，表单随类型变——demo 已采用。
3. **上传零摩擦**（Discourse/知乎）：拖拽、粘贴截图直接变图片。demo 目前是选择器上传，这是下一步。
4. **颜色格式不要做**：没有任何一家支持任意字体颜色。社区内容里彩色文字几乎必然被滥用、可读性差。语义格式（粗体/引用/标题）够了。
5. **HTML 不直出**：XSS 风险 + 多端渲染不一致。统一内部格式为「安全子集 HTML」（b/i/u/h2/h3/blockquote/pre/code/a/img），MD 只是输入方式之一。

### 结论
学生社区采用 **Reddit 式双模式**：默认富文本（contenteditable + 精简工具栏），一键切 Markdown 源码并互转。不支持字体颜色与 HTML 源码编辑。

## 2. 帖子的交互全集

| 类别 | Reddit | X | 知乎 | Discourse |
| --- | --- | --- | --- | --- |
| 表态 | ↑↓ 投票 | ❤ 赞 | 赞同/反对、喜欢 | ❤ 点赞（长按更多表情反应） |
| 收藏 | Save | 书签 | 收藏（夹） | Bookmark（可设提醒） |
| 关注 | Follow post（有新回复通知） | （评论默认通知） | 关注问题 | watching/tracking/normal/muted 四档 |
| 分享 | 复制链接 / crosspost | 复制链接 / 私信转发 | 微信 / 复制链接 | 复制链接 / 生成海报 |
| 传播 | crosspost | 引用转发 | 邀请回答 | 引用回复（quote block） |
| 治理 | 隐藏 / 举报 | 举报 | 举报 | 举报 / Flag |

归纳为四类：**表态 / 关系（收藏·关注）/ 传播（分享·引用·邀请）/ 治理**。
一个帖子详情页的标准配置：表态（投票或赞）→ 收藏 → 关注 → 分享 → 举报。demo 之前缺收藏/关注/分享，本轮补齐。

## 3. Demo 已实现（本轮）

- **双模式编辑器**：Aa 富文本（B/I/U/S、标题、引用、代码块、链接、6 色语义色板）↔ M↓ Markdown，互转；安全子集 HTML 存储 + 前端消毒（去 script/on* 属性）
- **收藏** ⭐：详情页/信息流可收藏，计数 +1，同步「我的记录 → 收藏」页签
- **分享** ↗：复制链接（演示含"生成分享海报"入口）
- **关注帖子** 🔔：切换关注状态，有新回复提醒（演示）
