# Umeet 兴趣社区首版：实现与运行说明

日期：2026-11-15。代码基于检查点 `d4c55ca`，分支 `codex/community-interest-v1`。本次只更新本地项目和预览，没有部署或推送远端。

## 已实现

- AI、科技、开源、Web3 技术四个非默认板块及 Wiki 空间。原板块、历史内容和订阅保留；新板块只有用户主动选择或点击订阅才加入侧栏。兴趣引导可跳过，发现页可再次调整。
- 首页增加规则推荐，依据主动订阅、标签、互动及时间计算，展示理由和“不感兴趣”。原有内容入口保留。
- 普通帖子详情中，作者可以附加单选投票，设置未来 90 天内截止时间；一账号一条有效票，可在截止前改选。首票后冻结问题与选项；提交携带版本，旧页面不会误投修改后的选项。只公开汇总。
- 资讯和预测分别是独立内容板块，与其他板块一起列在发现页，可订阅或取消订阅。订阅后显示在统一侧栏；详情支持评论、收藏、关注、复制链接和举报，关注者收到新评论和核验结果通知。系统采集与预测发布保持原流程，普通发帖器不向这两个内容板块发帖。
- 管理后台增加“资讯与预测”：来源配置及异常、免费模型状态、题型、每日任务、结果核验、举报及目标评论审阅、隐藏与恢复。沿用全站和板块管理权限、账号处罚及审计。

## 资讯

支持 GitHub release 元数据、JSON Feed、RSS/Atom。只取标题、原文地址、时间和来源明确提供的摘要；GitHub 不转载 release 正文。RSS 禁止 DTD/实体声明，并限制体积和 XML 深度。

每板块每个北京时间业务日最多发布五张卡，数据库事务处理并发配额；按来源条目标识、去掉跟踪参数后的原文 URL 去重，不声称已经完成跨媒体语义合并。未来时间或超过七天的条目不导入。不会补充假资讯。

采集只允许 HTTPS、配置的精确域名、公网解析地址；请求绑定已校验 IP，保留 TLS 主机校验，重定向重新校验。默认只允许 `api.github.com`；其他域名通过服务端 `INTEREST_SOURCE_HOSTS` 显式添加。采集每十五分钟一次条件请求，失败退避三十分钟；每轮最多处理三个来源。

初始化四个官方项目的来源：

```powershell
cd /path/to/project
node --env-file=.runtime/local-start-api.env --import tsx scripts/seed-interest-sources.ts
```

默认创建为未启用。在核对展示条件后，可从后台启用；显式添加 `--enable-metadata` 可以启用只展示发布元数据的模式。命令不会覆盖既有来源设置。本地预览已启用 Transformers、VS Code、Rust、Go Ethereum 四个来源，首次请求均成功；没有近七天合格更新的项目暂不出现卡片。

GitHub 官方文档说明公开 release 可无认证读取，分页默认 30 条；此初始化使用每页 10 条并控制请求频率。[官方 release API](https://docs.github.com/en/rest/releases/releases)。公开接口不代表全文转载授权，新增来源应分别核对[平台 API 条款](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#h-api-terms)及内容使用条件。

## 每日预测

API 服务启动后，以进程内独立串行循环检查每日任务。北京时间 08:00 起，领取当天唯一发布槽位。重启可以领取当天未运行的任务，晚启动时会迟发，实际发布时间与信息截止时间公开；不回填过去日期，也不伪装准点。运行依赖 API 进程在线，尚未确认生产服务器常驻、免费唤醒或 GPU 能力。

这条循环与既有任务队列独立，避免外部模型调用占住原任务处理器。数据库保留来源租约、每日槽位和调用预留。运行中的预测任务超过十五分钟可被重新领取；发布由业务日唯一约束兜底。网络超时后的外部调用不能承诺恰好一次，但重试仍受当日上限约束。

第一个可用题型是：指定官方 GitHub 仓库的精确 tag 是否会在截止前成为正式 release。管理员预置项目、目标 tag 和提前天数。最多检查十个候选，已发布目标自动停用并继续检查其他候选；同一来源和目标不重复出题。管理员可更新目标，形成后续候选。没有合格题目就暂停。

已发布的概率、理由、反向证据、截止时间和证据永久保留原值。后台修改题型不会改写旧记录；核验使用发布时冻结的来源和目标。只有符合规则的官方发布时间可以自动判定，缺失记录不会被当作“未发生”，而是转人工核验；结果和证据追加保存。Brier 分数只统计明确核验的二元结果。

政治、经济和比赛保留领域状态，但判定适配器和可用来源尚未接入，明确显示未就绪。本次不宣称这些领域已经能自动出题。

## 免费模型接入

目前没有已验证的生产免费模型配置，预测显示暂停；不会生成示例概率，也没有付费回退。本次未申请外部账号或发送私人帖子、私信给模型。

接入一个已确认允许服务使用、且不会自动计费的 OpenAI 兼容服务时，在 API 服务环境中设置：

```dotenv
INTEREST_AI_ENABLED=true
INTEREST_AI_FREE_ONLY_ACK=true
INTEREST_AI_URL=https://provider.example/v1/chat/completions
INTEREST_AI_HOSTS=provider.example
INTEREST_AI_MODEL=provider-model-id
INTEREST_AI_KEY=operator-provided-key
INTEREST_AI_DAILY_CALLS=2
```

示例域名不可直接使用，密钥不要提交 Git。`FREE_ONLY_ACK` 是操作员确认标记，不能替代对服务商免费条件的核实。接口无密钥也可以配置，但仍须显式声明域名与模型。模型只收到题目、规则和整理后的公开来源证据。

每日调用默认上限两次，可配置 0–10；发送前预留，失败也占次数。结构、概率范围和证据编号必须通过验证；额度耗尽、输出无效或来源异常均暂停。修复后可在管理页请求重试当天已暂停任务；已发布日期不能再次生成。
