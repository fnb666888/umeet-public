# Umeet Web 端社区交互设计方案（Demo 版）

> 依据《COMMUNITY-UX-RESEARCH.md》调研结论收敛成的可执行设计方案，并附可运行 HTML/CSS/JS demo（`demo/web-ux/`）。

## 1. 设计目标
让新用户 10 秒内明白：能看什么、能发什么、去哪发、去哪查。核心动作「看 → 发 → 聊 → 存知识」每一步都有可见入口和即时反馈。

## 2. 视觉方案

**气质**：校园布告栏 × 纸感文具。整体安静、留白多，唯一的高亮位留给「发帖」按钮——全站最显眼的绿色块。

**色板（4 主色 + 2 功能色）**
| Token | 值 | 用途 |
| --- | --- | --- |
| ink | `#22301f` | 正文/标题，深墨绿黑 |
| paper | `#faf8f0` | 页面底色，米白纸感 |
| card | `#ffffff` | 卡片面 |
| moss | `#3f6b3f` | 主绿：导航态、按钮、链接 |
| sun | `#f2c14e` | 热度/高亮（热门标、公告钉），唯一暖色，只用于"热" |
| leaf | `#e3edda` | 选中底、引用条底、标签底 |

**字体**：单一字族系统栈（`"Noto Sans SC", "PingFang SC", "Microsoft YaHei"`）。标题 700–800，正文 400，辅助 13px。不用衬线、不全大写、不加装饰性眉标。

**布局**：桌面三栏 `220px 侧栏 / minmax(0,680px) 主列 / 300px 右栏`；≤960px 收成单列 + 顶栏汉堡。左对齐为主，卡片内部信息左对齐、右端数字右对齐。

**动效**：只保留"回应动作"的过渡（点zan、出引用条、切页签），无进场动画，`prefers-reduced-motion` 关闭过渡。

## 3. 页面与交互规格（demo 实现范围）

### 3.1 全局壳
- 顶栏：logo｜搜索（输入即出下拉：帖子+Wiki 命中，回车进搜索页）｜**[＋ 发帖]** 绿色主按钮｜🔔（未读红点，下拉显示聚合通知）｜头像。
- 左栏：首页/发现/Wiki/我的记录 + 「我的社区」列表（社区名 + 今日帖数）。
- 右栏（首页/社区页）：社区活跃榜、今日热门帖。

### 3.2 首页 Feed（`#/`）
- 页签：🔥 热门（默认）/ 🕒 最新；置顶公告条（可关）。
- 卡片：社区徽 + 作者·时间；标题（大）；两行摘要；底部 `赞数 💬 回复数 · 内联 ♡ 可直接点`。
- 无限滚动：滚动到底自动"加载更多"（demo 用追加假数据模拟）；空态给发帖引导。
- 排序：热门 = 赞数 − 2×距发布小时数。

### 3.3 社区页（`#/c/:slug`）
- 社区头：名 + `成员/今日新帖/Wiki 词条` 统计 + 页签 讨论｜Wiki｜关于。
- 顶部常驻高亮 **「＋ 在此发帖」**（未登录弹登录提示 demo：直接放行）。
- 发帖不折叠、不藏 details。

### 3.4 发帖（`#/new?c=slug` 或弹层）
- 类型先行：进入先选板块（问答/交易/活动/树洞…），表单字段随类型变化（交易出价格，活动出时间地点）。
- 提交后 toast「已发布」+ 跳详情页。
- 树洞板块提交前 inline 提示匿名规则。

### 3.5 帖子详情（`#/posts/:id`）★
- 正文卡：标题、作者、正文、投票 ▲score▼、⚑ 举报收进小图标。
- 评论区：排序 [最热|最新]；**两级缩进树**（一级平铺、二级左竖线缩进）；超 3 条二级折叠「展开 N 条回复」；OP 徽标；评论 ♡；问答类楼主可「✓ 设为最佳」，最佳回复绿框置顶。
- **底部固定输入条**：点任意「回复」→ 输入条上方浮出引用条 `↩ 正在回复 A：前 30 字…`（可 ×）；发送后插入对应楼层并滚动高亮。
- 引用渲染：回复正文首行灰色引用行，点击滚到被引用楼层。

### 3.6 Wiki（`#/wiki`、`#/wiki/:id`）★
- 索引页：搜索框 + 「最近更新」行 + 目录卡（标题/摘要/章节数/更新时间）；空态引导建词条。
- 文章页：面包屑；正文左；右侧信息卡（最后编辑者/更新时间/修订数）+ TOC（≥3 个 H2 才出现，滚动高亮当前节）+ ✏️编辑 / 🕘历史 / 💬讨论 三入口。
- wikilink `[[词条]]`：存在则跳转，不存在 → 进入新建预填标题（demo 用 alert 提示路径）。

### 3.7 通知
- 铃铛下拉：聚合文案（`A、B 和另外 5 人赞了你的帖子`），点条目跳对应页。

## 4. 信息架构
```
首页#/  ├─ #/c/:slug（讨论|Wiki|关于）─ #/posts/:id
        ├─ #/wiki ─ #/wiki/:id（编辑|历史|讨论）
        └─ #/new（发帖）
```

## 5. Demo 说明
- 位置：`demo/web-ux/`，纯静态 `index.html + css/style.css + js/data.js + js/app.js`，无依赖，双击或任意静态服务器打开。
- 数据为 mock，页面用 hash 路由；交互实现范围即第 3 节所列。
- 后续接入真实后端的映射表见 `docs/COMMUNITY-UX-RESEARCH.md` 第 5 节优先级表。
