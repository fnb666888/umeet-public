# 标签（Tag / 话题）系统调研：X / Reddit / Discourse / 知乎

> 2026-11-07 · 问题：标签功能怎么做——自由打标签还是结构化管理？

## 1. 四家的做法

### X —— 自由 Hashtag（无管理）
- 正文里 `#话题` 自动变蓝链，点击进入该词的搜索结果页；无标签创建/审核——**用的人多了它就是标签**
- 探索页"趋势"列热门 hashtag（按地域聚合）
- 本质：标签 = 搜索的快捷方式，零管理成本，但噪声大、无结构

### Reddit —— Flair（社区自定义徽标）
- **Post Flair**：每个社区（subreddit）由版主预定义一套 flair（可带颜色/emoji），发帖时选择（可设必选）；列表可按 flair 过滤
- **User Flair**：用户在社区内的身份小标签（如"大三 · 计科"）
- 本质：**结构化、社区作用域、版主治理**；没有自由 hashtag

### Discourse —— 正式 Tag 系统（最完整）
- 管理员开启后：发帖时**标签选择器（带自动补全）**，可设某分类下"必选/可选"
- 标签页 `/tag/xxx` 聚合该标签下所有话题；可与分类组合过滤（`分类A + 标签B`）
- **标签组**（tag groups）管理相关标签；同义标签（synonyms）归并
- 话题列表标题旁显示小标签徽章；侧栏可按标签订阅
- 本质：**受控词表 + 自动补全 + 聚合页 + 通知订阅**

### 知乎 —— 话题（Topics，结构化最强）
- 问题绑定"话题"（如 大学、心理学），话题有父子层级、话题页（精华/讨论）、编辑维护
- 本质：**人工策划的分类法**，介于标签和目录之间

## 2. 结论

| 维度 | 自由标签（X） | 结构化标签（Discourse/知乎/Reddit Flair） |
| --- | --- | --- |
| 创建 | 谁都可以 | 词表内选择（可申请新建） |
| 治理 | 无 | 版主/管理员维护、可归并 |
| 发现 | 靠搜索/趋势 | 标签页聚合 + 组合过滤 + 订阅 |
| 适合 | 大流量泛社区 | **垂直校园社区（推荐）** |

**校园社区的建议**：采用 **Discourse 式受控标签**——
1. 预置标签池（期末周、图书馆、二手、搭子…），发帖时**自动补全选择**，最多 3 个
2. 列表卡片与详情页展示标签徽章，**点击进标签聚合页**
3. 右栏"热门标签"做发现入口；搜索命中标签
4. 新标签允许创建（真实产品中进审核队列）

## 3. Demo 升级清单（本轮实现）
- 发帖编辑器加**标签字段**：自动补全（预置标签池）+ 回车添加 + 上限 3 个
- 帖子卡片/详情页显示标签徽章，点击进 **标签聚合页**（`#/tag/名称`：帖子列表 + 关注按钮）
- 右栏新增 **热门标签**；搜索下拉命中标签
- 存量 mock 帖子补标签数据
