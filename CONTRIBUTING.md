# 参与共建 / Contributing

欢迎文档、翻译、设计反馈与问题复现。当前网站/API 从 `rebuild/` 开始，修改前阅读相关 `AGENTS.md`。

1. Issue 描述问题、场景、复现步骤和预期效果。
2. 大功能、迁移与 API 变更先讨论；小修复可直接发 PR。
3. 运行相关检查，集成测试只连接独立本地测试库。
4. PR 说明改动效果、验证方式和未验证部分，界面变更可附脱敏截图。

不要提交环境文件、私钥、备份或真实用户数据。日志与截图需移除个人信息、验证码和会话。不要公开可利用的安全漏洞或凭据；使用私密漏洞报告渠道，若未启用则先请求私密联系方式。

原创贡献采用 0BSD；引入第三方内容时注明来源并保留许可证。

---

Documentation, translations, design feedback, and reproducible bug reports are welcome. Start in `rebuild/` for the current website/API and read applicable `AGENTS.md` files.

1. Explain the problem, use case, reproduction steps, and expected behavior.
2. Discuss larger features, migrations, and API changes first; small fixes can go straight to a PR.
3. Run relevant checks with a dedicated local test database.
4. Describe resulting behavior, validation, and unverified areas. Include sanitized screenshots when useful.

Do not commit environment files, private keys, backups, or real user data. Remove personal information, codes, and sessions from logs and screenshots. Report exploitable vulnerabilities privately; if private reporting is unavailable, request a private contact channel first.

Original contributions use 0BSD. Identify third-party sources and preserve their licenses.
