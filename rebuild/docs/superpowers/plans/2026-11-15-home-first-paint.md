# 首页首屏实施计划

目标：按用户已选择的“服务端首屏帖子＋账号信息独立加载”方案实现，保留既有网站、权限与账号切换边界。

选择：复用已有社区视图并注入无身份首屏数据；不重写首页 UI。服务器只读取公开首页接口，禁用共享页面缓存。账号未初始化时，仅首页可显示公开内容，其他页面保留原有身份门禁。公开首屏不能成为当前账号的私有缓存或授权依据。

- [x] 新增只返回公开首批帖子及其公开回复的 bootstrap 接口，剔除个人状态、通知、联系人和用户资料。
- [x] 首页服务端读取 bootstrap；AccountSessionProvider 允许首页公开渲染，提供初始化状态。
- [x] 社区 Provider 在身份初始化后读取当前账号完整数据；首屏期间禁止执行依赖身份的操作，不显示“全部话题”假结尾，不提前触发登录对话框。
- [x] 测试隐藏内容、私有字段、身份隔离、无 JavaScript 的首屏和慢账号接口，运行现有导航回归及类型检查。
- [x] Linux 构建，通过后按既有直接发布授权激活；失败自动恢复前版，记录证据。
