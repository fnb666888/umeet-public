# 首屏身份与剩余导航加载

发布目录：/opt/umeet/releases/20261115-first-screen。

之前身份在浏览器启动后才读取；资讯/预测的 hook 每次挂载清空数据；群组与站点设置虽有请求缓存，但组件初始状态仍为空。后台预取仅覆盖部分列表。

本次在动态服务端布局验证会话，并将账号名传入首屏。首页携带有效会话时并行读取成员快照与匿名公共内容，成员读取上限 2200 ms，身份验证上限 1800 ms，异常时保留公共内容与客户端重试。所有个人读取 no-store，不跨用户缓存，不向浏览器传递会话密钥。身份显示不依赖浏览器账号列表；真实业务请求仍等待账号版本绑定，以保留跨账号响应隔离。

资讯/预测与治理读取采用账号、设备、版本隔离的内存缓存及在途合并；30 秒新鲜、最多 5 分钟旧内容供刷新期间展示。写入前后失效、401/403 清除。后台扩展预取至群组、站点设置、资讯管理、申请、团队、回收站及历史；群组和设置从缓存初始化，避免已准备数据仍闪加载。

验证：46 项前端测试通过；补充初始化请求时序回归后，浏览器账号 6 项测试通过；类型检查、本地及 Linux 生产构建通过。9 项专项浏览器检查包括禁用 JavaScript 首屏账号、账号列表延迟 3 秒、7 个预备后台菜单点击均通过，脚本错误 0。身份与后台专项在隔离本地 QA 环境进行，不冒用生产用户账号。

57 路径遍历、12 次导航点击无超时及脚本错误。旧别名 /c/daily/knowledge 返回 COMMUNITY_NOT_FOUND，实际社区为 /c/campus/knowledge；另一个编辑页提示保留不支持的 Markdown 原稿。这两项不记作成功的数据页面。路径报告保留实际 alerts。逐页时间是本地 QA 生产构建数据，不能代表公网。该次最慢首次已就绪时间 238 ms。

证据：first-screen-check-2026-11-15.json、first-screen-page-audit-2026-11-15.json、first-screen-public-2026-11-15.json，均位于 docs/evidence/performance/。

边界：未命中预取的首次数据读取仍有等待，服务器或网络故障时无法保证身份随首屏返回。后台权限与写入仍由服务器校验；本次没有数据库或付费设施变更。
