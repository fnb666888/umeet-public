# 首页与后台性能验收

发布日期：2026-11-15 17:05（Asia/Shanghai）。运行版本：`/opt/umeet/releases/20261115-home-bootstrap`。

## 修复

1. 首页服务端读取匿名 bootstrap，随 HTML 返回最多 20 个公开帖子及相应公开回复。移除账号、通知、联系人、用户资料与个人收藏等状态。不缓存整个页面，服务端预取超过 1800 ms 时降级至客户端读取。
2. 公开首页可以在账号初始化前显示；个人数据在身份确定后读取。公开 bootstrap 不写入个人快照缓存，身份依赖的写操作在此期间拒绝执行。
3. SiteLink 对社区 hash 路由保持原生 hashchange 行为，修复 Next Link 导致“发现”等入口不更新视图的问题；原生页面间仍使用客户端导航。
4. 用户列表先分页，再批量判断当前页的管理权限；同一请求复用已经验证的操作者权限。全站用户页不再读取帖子、Wiki、私信举报。普通管理员、版主和站点所有者的保护规则仍在服务器执行。
5. 管理快照独立读取并行执行；申诉列表复用当次读取的申诉和处置数据，空队列跳过无意义的动作查询。无处置效果时不再读取全部限制记录。
6. 会话认证复用已读会话信息，近期会话不再执行注定不更新任何记录的 UPDATE；身份版本、锚会话、封禁和撤销检查保留，不增加鉴权缓存。

## 页面点击与真实计时

早期遍历脚本含 networkidle 的 500 ms 与额外 100 ms 等待，旧的约 1.04 秒不能当作实际编译或渲染耗时。已更正脚本：等待当前 API 完成和 DOM 加载状态消失，不人为加入固定等待。

本地生产构建 + 隔离 MySQL：

- 57 条页面/兼容链接路径逐项进入及强制刷新，无超时、无脚本错误；覆盖主社区、板块、账号/私信、后台、Wiki 阅读/编辑与兼容跳转。
- 12 组主要导航实点与 10 组页面安全控件实点通过，包括“发现”和后台菜单。记录启用按钮数量；未在生产执行保存、删除、封禁等写操作。
- 页面刷新后就绪时间最高 239 ms；这是本地数据和网络条件，不能代表公网成绩。
- 独立浏览器计时：首页 FCP/LCP 164 ms，当前数据就绪约 246 ms。
- 禁用 JavaScript 时仍能看到隔离测试帖子；账号请求人为延迟 3 秒时，公开帖子约 182 ms 显示。
- 页面明细：[CSV](../evidence/performance/page-navigation-2026-11-15.csv)、[JSON](../evidence/performance/page-navigation-2026-11-15.json)。旧 Wiki 内容为空的兼容地址只验证跳转及缺失内容提示；不宣称完成不存在内容的编辑操作。

发布后真实公网浏览器：FCP/LCP 692 ms，首次完整客户端状态约 2073 ms；“发现”与返回首页实点成功，脚本错误 0。首页 HTTP 200，匿名请求后台数据仍返回 401，Web/API 健康检查通过。生产管理员完整交互未自动操作；权限和数据写入在隔离环境回归。

## 验证范围

类型检查、Linux Web/API 构建、首屏隐私测试、账号与会话测试、管理权限/处置/治理回归通过。数据库仍为远程 TiDB，约 140 ms 往返并未消失；本轮没有付费扩容、迁移数据库或把敏感数据放进公共缓存。
