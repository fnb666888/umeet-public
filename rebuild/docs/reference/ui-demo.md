# Umeet UI 演示

用浏览器直接打开 `index.html`。无需安装依赖、构建或连接后端。

这是用于讨论产品和界面的独立原型，不是已经上线的服务。旧项目代码、数据库和部署均不受影响。

## 体验入口

- 首页：六个固定社区、混合信息流、最新/热门、已加入、内容类型筛选。
- 社区：进入某个社区，查看动态、加入/退出、进入其独立 Wiki。
- Wiki：词条分类、阅读、可视化/Markdown 切换、保存、历史前后对照、回滚。
- 日常互动：赞踩、收藏、评论、示例报名、创建内容、提交社区创建申请。
- 登录：点右上角头像退出，再体验微信/邮箱/手机/密码四种演示流程。
- 搜索：搜索帖子、资源与独立 Wiki 词条；快捷键 `/` 聚焦搜索。

默认登录身份是示例用户“南星”。发布、编辑和收藏等数据保存在当前浏览器的本地存储中。关于页面可重置演示数据。

## 明确的演示边界

- 无真实登录、微信二维码、邮件/短信发送、自动审核或后台 API。
- 无真实上传下载；文件选择只记录文件名，资源卡展示模拟文件。
- Wiki 基础编辑支持文字、标题、加粗、引用、列表、链接、代码和简单表格。公式暂以文本标记展示；没有接入数学排版或图片上传。
- 版本对照采用全文前后展示，尚非正式逐段差异编辑器。
- 社区申请保存为待审核，不自动创建真实社区。人数、初始帖子、评论与贡献记录是示例。
- 仅用于探索 UI，不代表整体设计文档已批准或正式技术栈已确定。

## 视觉方向

- 背景 `#f5f6f9`，内容白色，正文 `#202639`，次要信息 `#7a8192`。
- 主操作与 Wiki 链接使用蓝色 `#405ce6`；赞同反馈使用珊瑚色 `#ef7058`。
- 界面优先使用系统中文字体，标题以字号与字重建立层级，不引入外部字体或图像请求。
- 桌面固定社区侧栏、中央信息流、右侧发现与共建信息；窄屏将侧栏折叠为抽屉，隐藏次要发现栏。
- 社区图标的颜色有稳定的内容类别含义；Wiki 以长文阅读、目录和修订信息建立与动态的区别。

## 文件

- `index.html`：界面结构与入口。
- `styles.css`：完整响应式样式。
- `app.js`：路由、示例数据与本地交互。

浏览器本地文件地址仅供本机使用。需要跨设备分享时，应将这个目录作为静态文件提供访问。
